# Product Management System

A console-based Product Management System built with Python and CSV file handling.

## Features

* Add Product
* View Products
* Search Product by ID
* Update Product
* Delete Product
* Add Stock
* Sell Product
* Track Sold Quantity
* Calculate Total Inventory Value
* Generate Inventory Report
* Track Low Stock Products
* Track Out-of-Stock Products
* Calculate Total Sales

## Technologies Used

* Python
* CSV
* File Handling
* Functions
* Loops
* Conditions
* Dictionaries

## Data Storage

Product information is stored in a CSV file:

```text
Data.csv
```

The CSV file contains:

* Product Name
* Product ID
* Product Price
* Product Quantity
* Sold Quantity

## How to Run

Clone the repository and run:

```bash
python main.py
```

The program automatically creates `Data.csv` if it does not already exist.
